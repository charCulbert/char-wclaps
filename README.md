# char-wclaps

I'll upload some WCLAP plugins here for testing.

## plugin list

- MNO: an analog style mono synth using a webview gui with a scope.
- Tapa: an FM based drum synth.
- Mote: a MIDI arpeggiator.

- Clap Saw Demo Imgui: a wclap port of [the free-audio project](https://github.com/free-audio/clap-saw-demo-imgui). This builds the Imgui code separately to WASM, so it depends on a host that is expecting that via the clap.gui and clap.webview3 extensions. Try [my web DAW](https://daw.charlieculbert.com) as an example.
